# Abu Nasir Patwary — Personal Website

A lightweight, responsive academic and software portfolio inspired by the minimalist dark layout shared as a design reference.

## Pages
- `index.html` — homepage and introduction
- `research.html` — selected research manuscripts
- `projects.html` — selected software projects
- `assets/Abu_Nasir_Patwary_CV.pdf` — downloadable CV

## Built with
- HTML
- CSS
- Vanilla JavaScript
- Google Fonts (IBM Plex Mono)
- GitHub Pages

## Run locally
Open `index.html` in a browser. For a local development server, use the VS Code Live Server extension.

## Publish with GitHub Pages
1. Create a GitHub repository named `AbuNasirPatwary.github.io` (or use an existing repository).
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Before publishing
- Confirm the CV PDF in `assets/` is the latest version.
- Check that all contact details and research statuses are current.
- Replace or remove any content you do not want public.
- The portrait is included because it was supplied for this website.
